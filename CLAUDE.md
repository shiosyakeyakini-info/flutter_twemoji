# CLAUDE.md

## What this repository is

A fork of [jasonlessenich/flutter_twemoji](https://github.com/jasonlessenich/flutter_twemoji) whose
Twemoji assets track [jdecked/twemoji](https://github.com/jdecked/twemoji), the fork that keeps
following Unicode now that twitter/twemoji is dormant. The Flutter widget layer is upstream's; what
this fork adds is the tooling that keeps the assets and the emoji regex current.

## Commands

```bash
flutter pub get
flutter test                      # asset/regex consistency checks
flutter analyze --no-fatal-infos  # infos are pre-existing (deprecations, line length)

tool/sync_twemoji.sh                # sync with the newest upstream release
tool/sync_twemoji.sh --ref v17.0.3  # sync with a specific release
tool/sync_twemoji.sh --print-current
```

## Generated files — do not edit by hand

Run `tool/sync_twemoji.sh` instead; editing these by hand is silently undone by the next sync.

- `assets/png/`, `assets/svg/` — copied from the upstream `assets/72x72` and `assets/svg`
- `lib/src/twemoji_version.dart` — records the upstream repository and release
- the `// twemoji-regex:begin`…`:end` block in `lib/src/utils.dart` — `TwemojiUtils.emojiRegex`,
  generated by `tool/update_emoji_regex.mjs` from the `@twemoji/parser` npm package (the same
  source Twemoji builds its own `twemoji.js` from)

Assets and regex have to come from the same release: syncing assets alone leaves new emoji
unmatched by `TwemojiText`, and `flutter test` fails when the two drift apart. The regex is embedded
in a Dart string that resolves the `\uXXXX` escapes before `RegExp` sees them, so the generator
rejects any upstream pattern that would need different escaping rather than emitting broken Dart.

## Layout

- `lib/src/twemoji_widget.dart` — `Twemoji`, a single emoji as an SVG or 72x72 PNG asset
- `lib/src/twemoji_text.dart`, `twemoji_text_span.dart` — text with inline emoji, split via
  `TwemojiUtils.emojiRegex`
- `lib/src/utils.dart` — the regex plus `toUnicode`, which maps an emoji to its asset file name
- `bin/include_emojis.dart` — `dart run flutter_twemoji:include_emojis`, filters the bundled assets
  down to the emoji listed under `flutter_twemoji: includes:` in the consumer's pubspec
- `example/` — demo app

## Workflows

- `.github/workflows/sync-twemoji.yml` — manual (`workflow_dispatch`) only, opens a pull request
  with the sync result. Deliberately not on a schedule: upstream publishes a few releases a year,
  and GitHub disables scheduled workflows in public repositories after 60 days without a commit.
- `.github/workflows/ci.yml` — `flutter analyze` and `flutter test`

## Releasing

`pubspec.yaml` `version` and a `CHANGELOG.md` entry are bumped by hand, not by the sync. The
package name still collides with the upstream package on pub.dev, so this fork is meant to be
consumed as a git dependency unless it is renamed first.
